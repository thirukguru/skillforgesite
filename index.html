Everything in one place

One home for skills, agents, and rules

SkillForge scans the dotfiles every tool hides away and gives them a single, searchable, editable home.

Auto-discovery

Crawls your home directory to find Claude, Cursor, Codex, Windsurf, Antigravity and more — no manual setup on macOS.

Editor + live preview

A real markdown editor (CodeMirror) with syntax highlighting, plus a rendered preview a keystroke away.

Skills, agents & rules

Rules are first-class — Cursor .mdc globs and alwaysApply surfaced as badges, not buried in YAML.

Collections

Group related skills into named, icon-tagged collections that live in the app — never touching your source files.

Copy across tools

Share one skill everywhere — copy a Claude skill straight into Cursor or Codex without leaving the app.

Keyboard-first

⌘K search, ⌘E/⌘P edit & preview, ⌘S save, ⌘⌫ delete. Fly through your library without touching the mouse.

Free & open source

SkillForge is open source and in active development. Grab the code and build it yourself — signed, notarized installers for macOS, Windows, and Linux are coming soon.
